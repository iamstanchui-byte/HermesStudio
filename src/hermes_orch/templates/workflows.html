How to use

  1. Open a completed project (state = completed / failed / cancelled / interrupted).
  2. Click "🔁 Promote to workflow" — pick a name + optional description.
  3. LLM synthesizes a step_template (with {{ '{{var}}' }} placeholders) + variables list.
  4. The new workflow appears here, click to view / edit / delete.
  5. Click "▶ Run with variables" on the workflow detail page to spawn a fresh project with substituted values. Or "📥 Apply" on a project page to import the workflow's steps into an existing project as new tasks (additive — existing tasks are kept).
