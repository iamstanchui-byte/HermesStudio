Each project lives in its own subfolder here. The agent wrappers read/write files via the orchestrator's file API, so a shared folder path on this host works fine for both Windows and Linux agents (no SMB mount needed on agents).

Examples: C:\Project\minimax code\hermes-project (Windows) · /home/stanley/hermes-project (Linux) · \\fileserver\share\hermes-project (UNC)
⚠ Changing the path does NOT move existing projects. Old projects stay where they were created.

Cleanup job (hard-delete old soft-deleted projects)

Projects in the deleted state (soft-deleted) older than retention days are hard-deleted: row removed from projects (cascades to tasks, artifacts, sessions) and the project folder is wiped from disk. Audit log is preserved. Runs on server startup and every 24h, or you can trigger it manually below.

Projects in deleted state for longer than this are wiped.
Cleanup also runs once on server startup regardless.
