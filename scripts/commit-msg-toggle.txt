Dashboard: real toggle switch + dark mode

User feedback: the previous "10s polling" text wasn't
visually clear as a toggle (no visual cue that it was
clickable). Replaced with a proper iOS-style switch UI:
- "Auto-refresh" label + pill-shaped toggle (knob slides
  left/right, blue when on, gray when off)
- Click anywhere on the button to toggle
- State persisted in localStorage

Dark mode (user request #2 from earlier):
- Toggle button next to auto-refresh: sun/moon icon + label
- Light mode = sun icon, Dark mode = moon icon
- Theme persisted in localStorage as 'orch.theme' = 'dark'|'light'
- CSS block in base.html overrides the most common Tailwind
  color classes when body has .dark class:
  - bg-white -> gray-800, bg-gray-50/100/200 -> darker grays
  - text-gray-800/700/600/500 -> lighter grays
  - border-gray-200 -> gray-700
  - badge backgrounds preserved (green for ready, yellow
    for mock, etc.) but with darker tints and lighter text

Implementation:
- base.html CSS: ~30 lines of toggle + dark mode overrides
- base.html script: rewritten to use setAutoRefreshUI() /
  setTheme() helpers that just toggle the .toggle-on /
  .dark class. The previous badge-color approach was
  replaced with class toggles so the switch visually
  matches the rest of the UI.

Init order: theme is applied from localStorage BEFORE the
body renders to avoid a flash of light mode on dark-mode
preference. Polling is then started after both toggles
are in their persisted state.
